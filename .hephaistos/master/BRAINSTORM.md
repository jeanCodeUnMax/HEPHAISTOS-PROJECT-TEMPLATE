# BRAINSTORM (Maieutic Socratic Gate)

## 1. Objectif (Purpose)
- **But profond** : Créer un mini-jeu de type casse-briques (Arkanoid) dans un univers Cyberpunk rétro-futuriste.
- **Volonté** : Démontrer le fonctionnement de bout en bout du système Hephaistos (du plan au code) en créant un produit jouable, esthétique, et fonctionnel.
- **Obtention in fine** : Un jeu web simple (HTML5 Canvas + Vanilla JS) avec une esthétique néon/glitch.

## 2. Utilisateurs (Users)
- Le joueur lambda cherchant une petite expérience d'arcade rapide.
- Le développeur (pour la démo Hephaistos).

## 3. Périmètre (Scope)
- **Must-have** : 
  - Raquette contrôlable (souris/clavier).
  - Balle avec physique de rebond.
  - Grille de briques destructibles.
  - Esthétique visuelle Cyberpunk (couleurs Néon, fond grid/synthwave).
  - Condition de victoire et défaite (Game Over / You Win).
- **Nice-to-have** :
  - Sons synthwave basiques.
  - Effets de particules ou de "glitch" lors de la destruction d'une brique.

## 4. Architecture & Contraintes
- **Stack** : Vanilla HTML, CSS, JavaScript (pas de frameworks).
- **Rendu** : HTML5 `<canvas>`.
- **Fichiers** : `index.html`, `style.css`, `game.js`.
